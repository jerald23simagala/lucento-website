# Logo concepts, round 2

Revisions of Sunrise Coin (2a, 2b) and Rising Crest (3a, 3b), plus Keeper's Torch (1)
and Daylight Dial (4) rebuilt with the same asset set so all six can be compared fairly.
None of these is a chosen direction.

Each folder contains:

| File | What it is |
|------|------------|
| `symbol-light.svg` | Full-colour symbol for light backgrounds |
| `symbol-dark.svg` | Full-colour symbol for dark backgrounds |
| `symbol-mono.svg` | Single-colour symbol; uses `currentColor` (set `color` where it's placed) |
| `wordmark-light.svg`, `wordmark-dark.svg` | Wordmark only, navy or ivory, converted to outlines |
| `wordmark-mono.svg` | Wordmark only, `currentColor` |
| `android/ic_launcher_foreground.svg` | Adaptive-icon foreground on the 108 dp canvas, artwork inside the 66 dp safe zone |
| `android/ic_launcher_monochrome.svg` | Themed-icon layer (Android 13+) |
| `android/ic_launcher_background.txt` | Background colour for the adaptive icon |
| `previews/sizes.png` | 16, 24, 48 px renders (light, dark, mono), 4× and actual size |
| `previews/android.png` | Circle and squircle masks, themed icon, Play Store size, 48 px launcher |

`compare-sizes.png` and `compare-android.png` put all six side by side.

Wordmarks are outlined from Fraunces 600 (2a, 2b), Sora 600 (3a, 3b) and Manrope 800/700
(1, 4), all SIL Open Font License. Letter-spacing is applied; pair kerning is not, so the
chosen wordmark still needs hand spacing before production.
